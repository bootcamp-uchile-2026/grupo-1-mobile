# StyleNow - Aplicación Móvil (Hito 1)

Bienvenido al repositorio de desarrollo de la aplicación móvil de **StyleNow**, una plataforma E-commerce moderna diseñada para combatir la desconfianza del usuario al comprar vestuario en línea mediante una experiencia visual e inspiracional.

Este prototipo nativo ha sido construido utilizando **Kotlin** y **Jetpack Compose** bajo el patrón de arquitectura **MVVM**.

---

## Requisitos Rápidos

* **IDE:** Android Studio (Koala o superior recomendado)
* **SDK Mínimo:** API 7 (Android 8.1)
* **SDK de Destino (Target):** API 37 o superior
* **Versión Kotlin:** 2.4.10
---

## Cómo Ejecutar la Aplicación

Debido a que el proyecto está configurado con Gradle y utiliza datos simulados locales (`DefaultData`), no requiere configuraciones complejas de bases de datos ni llaves de API externas para este Hito. Android Studio se encarga de todo el proceso de inicialización:

1. **Clonar el repositorio:**
   ```bash
   git clone -b main https://github.com/bootcamp-uchile-2026/grupo-1-mobile.git
   ```
2. **Abrir en Android Studio:** Selecciona *Open* y elige la carpeta del proyecto StyleNow.
3. **Sincronizar Gradle:** Deja que el IDE descargue las dependencias automáticamente (o presiona el botón *Sync Project with Gradle Files* si es necesario).
4. **Ejecutar:** Conecta tu teléfono Android personal (con depuración USB activa) o inicia un emulador y presiona el botón *Run* (ícono de play verde).
